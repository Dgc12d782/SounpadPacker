# SoundpadPacker

tiny util that takes an .spl soundpad file, fetches all the files from it and copies them into a given directory, then copies the given .spl into that directory and patches the paths in it
features ffmpeg-based mp3 conversion, put ffmpeg.exe next to the .py (or vice versa)



# Installation

Get python
Install all requirements
Get the script
Transfer FFMPEG exe to the script folder



# Usage

Folllow the instructions it gives.
